# Holub Life Game 설계 패턴 팀프로젝트

## 개발 환경
- JDK 21 이상
- Maven 
- JUnit 5

## 실행
- main 진입점: `com.holub.life.Life`

command:
  ```
  mvn compile
  java -cp target/classes com.holub.life.Life
  ```

## 테스트
```
mvn test
```
